# Lab: Task System（中等）

## 背景

s03 的 `TodoManager` 是内存里的扁平清单：没有依赖关系，上下文压缩后就丢了。真实的工作是有结构的——任务 B 依赖任务 A，任务 C 和 D 可以并行，任务 E 要等 C 和 D 都完成。

解决方案：把扁平清单升级为**持久化到磁盘的任务图**。每个任务是一个 JSON 文件，有状态和依赖关系（`blockedBy` / `blocks`）。即使上下文被压缩、程序重启，任务状态都还在。

```
.tasks/
  task_1.json  {"id":1, "status":"completed"}
  task_2.json  {"id":2, "blockedBy":[1], "status":"pending"}
  task_3.json  {"id":3, "blockedBy":[2], "status":"pending"}

完成 task 1 → 自动从 task 2 的 blockedBy 里移除 1 → task 2 解锁可以开始
```

---

## 你的任务

在 s02（基础工具）的基础上，新建 `my-agents/s07.py`，实现一个 `TaskManager` 类和 4 个任务工具。

---

## Part 1：TaskManager 基础结构（简单）

实现 `TaskManager` 类，初始化时：
- 接收一个 `tasks_dir` 路径，创建目录（如果不存在）
- 扫描已有的 `task_*.json` 文件，找到最大 ID，用于生成下一个任务 ID

需要实现两个内部方法：
- `_load(task_id)` — 从磁盘读取一个任务 JSON
- `_save(task)` — 把任务写入磁盘

**提示：**
- 文件名格式是 `task_{id}.json`，用 `Path.glob("task_*.json")` 扫描
- 从文件名提取 ID：`int(f.stem.split("_")[1])`

---

## Part 2：CRUD 方法（中等）

实现 4 个方法：

1. `create(subject, description="")` — 创建任务，状态默认 `pending`，`blockedBy` 和 `blocks` 默认空列表
2. `get(task_id)` — 返回单个任务的 JSON
3. `list_all()` — 列出所有任务，用 `[ ]`/`[>]`/`[x]` 标记状态
4. `update(task_id, status, add_blocked_by, add_blocks)` — 更新状态和依赖

**提示：**
- `create` 每次调用后 `_next_id` 要 +1
- `list_all` 参考 s03 的 `render()` 方法，但要额外显示 blockedBy 信息
- `update` 的参数都是可选的（`status=None, add_blocked_by=None, add_blocks=None`）

---

## Part 3：依赖解除（中等）

这是 s07 的核心机制。当一个任务被标记为 `completed` 时，需要：

1. 遍历 `.tasks/` 目录下所有任务文件
2. 如果某个任务的 `blockedBy` 列表里包含刚完成的任务 ID，将其移除
3. 保存修改后的任务

实现为 `_clear_dependency(completed_id)` 方法，在 `update` 里当 `status == "completed"` 时调用。

**提示：**
- 这是单向操作：只从其他任务的 `blockedBy` 里移除
- `list.remove(value)` 可以按值删除列表元素

---

## Part 4：双向依赖关联（中等/困难）

当 `update` 传入 `add_blocks=[3, 4]` 时，意思是"当前任务阻塞了任务 3 和 4"。需要同时：

1. 把 `[3, 4]` 加进当前任务的 `blocks` 列表
2. 反向更新：把当前任务的 ID 加进任务 3 和任务 4 的 `blockedBy` 列表

**提示：**
- 用 `set` 去重：`list(set(task["blocks"] + add_blocks))`
- 反向更新时要 `_load` → 修改 → `_save` 每个被阻塞的任务
- 被引用的任务可能不存在，用 `try/except` 跳过

---

## Part 5：注册工具（简单）

把 4 个任务方法注册到 `TOOL_HANDLERS` 和 `TOOL_DECLARATIONS`：

- `task_create` — 必填 `subject`，可选 `description`
- `task_update` — 必填 `task_id`，可选 `status`、`addBlockedBy`、`addBlocks`
- `task_list` — 无参数
- `task_get` — 必填 `task_id`

**提示：**
- `task_id` 的类型是 `integer`，不是 `string`
- `addBlockedBy` 和 `addBlocks` 类型是 `array`，`items` 类型是 `integer`
