# Lab: Subagents（中等）

## 背景

s03 的智能体每次工具调用的输出都永久留在 `messages` 里。让它"读 5 个文件找测试框架"，这 5 个文件的全部内容就塞进了上下文，但父智能体其实只需要一个词：`"pytest"`。

上下文越来越胖，模型越来越容易分心。

解决方案：把子任务交给一个拥有**全新 `messages=[]`** 的子智能体去做，它干完活后只把最终文字摘要返回给父智能体，自己的整个消息历史直接丢弃。

```
Parent agent                     Subagent
+------------------+             +------------------+
| messages=[...]   |             | messages=[]      |  <-- fresh
|                  |  dispatch   |                  |
| tool: task       | ----------> | while tool_use:  |
|   prompt="..."   |             |   call tools     |
|                  |  summary    |   append results |
|   result = "..." | <---------- | return last text |
+------------------+             +------------------+

Parent context stays clean. Subagent context is discarded.
```

## 你的任务

在 `s03_todo_write.py` 的基础上，新建 `my-agents/s04.py`，为父智能体增加一个 `task` 工具，调用时启动一个子智能体完成子任务。

---

## Part 1：子智能体的系统提示（简单）

在文件顶部新增一个 `SUBAGENT_SYSTEM`，与原有 `SYSTEM` 区分：

- 原 `SYSTEM` 告诉模型它是主智能体，可以用 `task` 工具委派任务
- 新 `SUBAGENT_SYSTEM` 告诉模型它是子智能体，完成给定任务后输出摘要

**提示：**
- 子智能体不需要知道"自己可以再派子任务"，不要在 `SUBAGENT_SYSTEM` 里提 `task` 工具

---

## Part 2：子智能体的工具列表（简单）

子智能体拥有 `bash`、`read_file`、`write_file`、`edit_file`，但**没有** `task`。

新建 `CHILD_TOOL_DECLARATIONS`，从现有工具定义复制这四个即可。

父智能体的工具列表在此基础上再加 `task`：

```python
PARENT_TOOL_DECLARATIONS = CHILD_TOOL_DECLARATIONS + [
    {"name": "task", ...}
]
```

`task` 工具需要一个 `prompt` 参数（字符串），告诉子智能体要做什么。

**提示：**
- 为什么禁止子智能体使用 `task`？想想如果允许会发生什么

---

## Part 3：实现 `run_subagent(prompt)`（中等）

这是本 lab 的核心。函数签名：

```python
def run_subagent(prompt: str) -> str:
```

要求：

1. 用 `[{"role": "user", "parts": [{"text": prompt}]}]` 初始化一个**全新的** `sub_messages`，不能复用父智能体的 `messages`
2. 在内部运行一个完整的 agent loop，使用 `CHILD_TOOL_DECLARATIONS` 和 `SUBAGENT_SYSTEM`
3. 加一个安全上限，最多循环 30 次，防止子智能体无限运行
4. loop 结束后，从最后一次响应的 `parts` 里提取纯文字，作为返回值
5. 如果没有文字内容，返回 `"(no summary)"`

**提示：**
- `run_subagent` 内部的 loop 结构和 `agent_loop` 几乎一样，区别只是用 `sub_messages` 和 `CHILD_TOOL_DECLARATIONS`
- 最后一次响应的 `parts` 存在哪里取决于你怎么写循环，注意在 `break` 之前保存它
- 提取文字：`"".join(p.text for p in last_parts if hasattr(p, "text") and p.text)`

---

## Part 4：在父循环里处理 `task` 工具调用（简单）

修改 `agent_loop`，当 `fc.name == "task"` 时，调用 `run_subagent(fc.args["prompt"])`，其余工具照旧走 `TOOL_HANDLERS`：

```python
if fc.name == "task":
    output = run_subagent(fc.args["prompt"])
else:
    handler = TOOL_HANDLERS.get(fc.name)
    output = handler(**fc.args) if handler else f"Unknown tool: {fc.name}"
```

## 验证

运行你的代码：

```sh
python my-agents/s04.py
```

输入以下 prompt 测试：

```
Use a subtask to find what files are in the agents/ directory
```

预期行为：
- 终端打印 `> task (...): ...`，说明父智能体派出了子任务
- 子智能体执行 bash，父智能体收到的只是一段摘要文字
- 父智能体的 `messages` 里**没有**子智能体的工具调用记录

用这个 prompt 进一步验证上下文隔离：

```
Use a task to read requirements.txt, then tell me what you see
```

如果子任务的文件内容没有出现在父智能体后续的回复推理里（它只知道摘要），说明隔离成功。
